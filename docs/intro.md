# Learnissimo

## Problem Statement

When learning from a book, a textbook, or exam material, a user who tries to fully understand what they are reading is often simultaneously trying to memorize it, write it down, or build a conspect. Splitting attention this way gets in the way of understanding, and the resulting notes are still an imperfect record of what was actually understood or will be retained.

- Note-taking and summarizing while reading compete with comprehension for the same attention.
- Without a way to check retention afterward, the user does not know which parts of the material need more work.

## Proposed Solution

Learnissimo takes over the memorization and verification work, so a user can read for understanding alone. Quiz items are built for a specific section of a source — a chapter, a paragraph, an exam ticket — either generated automatically from the source or built from the user's own brief notes fed into Learnissimo. Each quiz item is grounded in a fact, and where that fact comes from a source, the quiz item is linked to the exact place in the source it comes from.

- Quiz items are tailored to what a given user finds important, not created to exhaustively cover every fact a source could yield.
- Learnissimo effectively builds the conspect a user would otherwise write by hand, but as references to specific points in the source paired with quiz items grounded in those points, rather than as a summary.
- Taking a quiz shows the user what is understood and what needs review, and a quiz item tied to a source leads back to its source location on demand.
- The user creates and modifies quiz items from a source, and Learnissimo provides the tools for that.
